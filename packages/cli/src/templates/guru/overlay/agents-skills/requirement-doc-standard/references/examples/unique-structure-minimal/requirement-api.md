# 服务端 API 需求

## API-INTENT-001 上传简历并创建导入任务

- 交互描述：用于上传简历文件并创建导入任务回执。
- 对应场景：`REQ-UC-001`
- 对应页面：`requirement-web-console.md` 第五章。

### 必要步骤

- 成功返回前，必须保存上传文件元数据、创建导入任务并返回任务编号。

### 输入

- `file_token`：上传后的文件标识，必填。
- `operator_id`：操作人标识，必填。

### 输出

- `task_id`：导入任务编号。
- `accepted_count`：已接收的简历条数。

### 异常

- 文件缺失：返回参数错误。
- 文件格式不支持：返回业务错误。
- 创建任务失败：返回系统错误。

## API-INTENT-002 查询简历列表

- 交互描述：用于支持简历列表页检索和筛选。
- 对应场景：`REQ-UC-002`
- 对应页面：`requirement-web-console.md` 第三章。

### 输入

- `keyword`：检索关键词，可选。
- `city`：城市筛选，可选。
- `education`：学历筛选，可选。
- `page_no`：页码，必填。
- `page_size`：每页数量，必填。

### 输出

- `total`：总条数。
- `items`：简历摘要列表。

### 异常

- 参数非法：返回参数错误。
- 查询失败：返回系统错误。

## API-INTENT-003 更新简历基础信息

- 交互描述：用于简历详情页保存编辑结果。
- 对应场景：`REQ-UC-003`
- 对应页面：`requirement-web-console.md` 第四章。

### 必要步骤

- 成功返回前，必须保证保存后的基础信息可被详情页与列表页后续读取。

### 输入

- `resume_id`：简历 ID，必填。
- `name`：姓名，必填。
- `phone`：手机号，必填。

### 输出

- `updated_at`：更新时间。

### 异常

- 必填缺失：返回参数错误。
- 简历不存在：返回业务错误。
- 更新失败：返回系统错误。
