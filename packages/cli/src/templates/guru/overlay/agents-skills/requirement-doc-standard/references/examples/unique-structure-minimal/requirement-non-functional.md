# 非功能需求

## 场景追踪

| 非功能主题 | 适用场景/入口 |
| --- | --- |
| 性能 | `REQ-UC-002` / `API-INTENT-002` |
| 安全 | `REQ-UC-001` / `API-INTENT-001`；`REQ-UC-003` / `API-INTENT-003`；`REQ-UC-004` / `CLI-INTENT-001` |
| 可用性 | `REQ-UC-001` / `API-INTENT-001`；`REQ-UC-003` / `API-INTENT-003` |
| 兼容性 | `REQ-UC-001`；`REQ-UC-002`；`REQ-UC-003` |

## 1. 性能

- 列表查询接口 P95 响应时间 <= 800 ms。
- 列表页首屏可见数据加载时间 <= 2 s。

## 2. 安全

- 所有写接口必须进行身份认证与权限校验。
- CLI 全量同步命令必须进行执行权限校验。
- 涉及个人信息字段的日志输出需脱敏。

## 3. 可用性

- 外部依赖短暂失败时，页面需提示可重试。
- 用户可在失败后不丢失已输入表单内容。

## 4. 兼容性

- 管理控制台支持最新版 Chrome 与 Edge。
- 页面在 1366x768 与 1920x1080 分辨率下可正常使用。
