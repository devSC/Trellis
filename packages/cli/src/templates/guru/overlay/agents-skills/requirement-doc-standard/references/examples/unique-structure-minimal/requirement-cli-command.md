# CLI Command 需求（若适用）

## CLI-INTENT-001 同步全量简历数据

- 交互描述：用于触发简历数据全量同步流程。
- 对应场景：`REQ-UC-004`（以主需求文档定义为准）。
- 业务意图：在运维窗口触发全量同步，并返回可供自动化任务判断的结果摘要与退出码。

### 命令

- `resume-tool sync --all`

### 参数

- `--all`：全量同步开关，必填。
- `--dry-run`：仅校验不落库，可选。

### 输出语义

- 成功：输出同步成功条数和耗时摘要。
- 失败：输出错误分类与重试建议。

### 退出码

- `0`：执行成功。
- `2`：参数错误。
- `3`：业务校验失败。
- `5`：系统错误。

### 异常

- 参数非法：返回参数错误并退出码 `2`。
- 权限不足：返回业务错误并退出码 `3`。
- 执行失败：返回系统错误并退出码 `5`。
