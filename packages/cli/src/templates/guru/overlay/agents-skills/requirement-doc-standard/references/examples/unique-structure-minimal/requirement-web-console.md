# 前端页面详细需求

## 第三章：P-001 简历列表页

### 3.1 页面目标

- 支持 `REQ-UC-002` 对应的关键词检索与多条件筛选。
- 支持查看候选人基础信息与最近更新时间。

### 3.2 关键组件

- 检索框：输入姓名、手机号或关键词。
- 筛选栏：按工作年限、城市、学历筛选。
- 列表表格：展示候选人摘要信息。

### 3.3 交互规则（主定义）

- 用户点击“搜索”后，系统按当前条件刷新列表。
- 用户修改筛选条件后，列表应基于新条件重新加载。
- 用户点击某一候选人后，进入详情页。
- 当结果为空时，页面显示空状态提示。

## 第四章：P-002 简历详情页

### 4.1 页面目标

- 支持 `REQ-UC-003` 对应的基础字段编辑与保存。
- 展示候选人详细信息。

### 4.2 关键组件

- 基础信息卡片。
- 编辑表单。
- 保存按钮与取消按钮。

### 4.3 交互规则（主定义）

- 用户点击“保存”后，系统校验必填项并提交更新。
- 更新成功后，页面提示成功并返回列表页。
- 更新失败后，页面展示失败原因并保留输入内容。

## 第五章：P-003 导入任务页

### 5.1 页面目标

- 支持 `REQ-UC-001` 对应的简历上传、导入任务创建与状态查看。
- 支持查看任务完成摘要与失败原因。

### 5.2 关键组件

- 文件上传区。
- 导入任务状态卡片。
- 失败条目摘要区域。

### 5.3 交互规则（主定义）

- 用户上传文件后，系统创建导入任务并展示 `task_id`。
- 任务执行中，页面展示当前状态与已处理数量。
- 任务完成后，页面展示成功数、失败数与失败原因摘要，并提供进入简历列表页的入口。
