## 5. 严重度判级规则

- **P1（阻断，不可进入详细设计）**：G1~G8 任一缺失；分层依赖律违例；双向断链（行为↔UC、owner↔索引）；粗粒度行为；pending L2 无豁免；真实 secret；高风险未决未关闭；双主定义（README/design.md 与 design-main 两套正文）。
- **P2（应修，可带明确假设进入）**：三问空洞；失败去向缺失；字段不全的技术决策（未被下游引用时）；越界（少量签名/字段合同——给回收方案）；图文局部不一致。
- **P3（建议）**：表述与术语一致性；格式偏离模板但语义完整。
- 判级冲突时取高；同一根因的多处表现合并为一条 finding（列全部位置）。

## 6. 结论判定

- 存在任一 P1 → **不可进入**（列阻塞清单与修订形态建议）。
- 仅 P2 且每条已有明确假设/修订路径 → **带明确假设可进入**（列假设与验证时点）。
- 无 P1/P2（P3 可遗留）→ **可进入详细设计**。
- 结论后必须给 Gate 收口指引（用户终端 confirm，见 SKILL.md）。
